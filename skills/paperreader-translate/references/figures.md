# 图表索引与校对

迁移上游 v2.1.11–v2.1.12 的原则：从实际 PDF 查找图表标题，原文与译文分别定位，优先裁出图表本身。使用现有 PyMuPDF；不调用 MinerU，不需要再次编译。

```bash
"$PYTHON" "$SCRIPT" figures /path/original.pdf \
  --translated /path/translated.pdf --output /path/figure-navigation
```

只有原文时省略 `--translated`。输出目录必须不存在；修改 PDF 后生成新目录，避免使用过期页码或预览。生成 `index.html`、`figures.json`、两侧 PDF 副本及 PNG 预览，可整体移动、离线阅读；点击预览打开对应 PDF 的页码。

## 定位与限制

- 支持 `Figure 2:`、`Fig. 2.`、`Table 2:`、`图 2.`、`表 2：` 等带数字及标点的标题。独占行首的标题优先于提取时与子图标签粘连的标题；普通正文里的 “in Table 2.” 不作为标题。
- 原文与译文各自检测，用图／表类型与编号对应。某侧没有匹配时明确标为“未定位”，不能复制另一侧页码。
- 图片及矢量绘图候选按邻近关系合并，并利用相邻标题限制跨栏合并；按论文常见布局查找图题上方的图、表题下方的横线表。其他标题位置可能回退整页。检测不到图形时，明确标记为整页回退预览，绝不声称已精确裁出。
- 这是辅助导航，不能据此认定全文图表覆盖完整。未编号图、缺少可提取文字的扫描页、罗马数字／字母编号、无横线表、重复编号、拆表多次出现及复杂多栏图组可能遗漏或裁剪不全。用原 PDF 和源码／MinerU 图表清单核对数量，检查裁图是否包含全部子图和坐标轴；必要时在工作副本手工裁切并注明。
- TeX 项目中的图表顺序应核对主文件及 input/include 的 figure/table 环境（含一个环境中的多个 caption），不能把资源目录中的所有图片都当成论文插图。本工具只索引已经编译的 PDF，不重写工程。
